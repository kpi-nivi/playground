# Python Data Foundations

Structured self-study covering Python for data engineering and analytics.
Scripts progress from core data structures to pipeline-relevant patterns.

## Topics Covered
- Data manipulation with Pandas (groupby, merge, reshape)
- File I/O — CSV, JSON, API responses
- Data cleaning patterns for real-world datasets
- SQL-to-Python translation (replicating SQL logic in Pandas)
- List comprehensions and functional patterns for ETL workflows
